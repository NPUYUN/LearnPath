# 记忆 / 复习型学习工具竞品脑暴

> 基于 LearnPath 当前能力：多会话对话、长期与实时画像、资源生成、路径重规划、AI 课堂、学习成就馆和后台管理。结论优先偏向「可立即落地」的小闭环，而不是新增大型模块。

**覆盖维度：** 交互体验 · 激励机制 · 内容呈现 · 个性化 · 社交 / 社区

## 本周优先落地建议（P0）

### Anki · 掌握度反馈

- **优先级：** P0 · **难度：** 中 · **体验提升：** 5/5
- **维度：** 个性化 / 交互体验
- **亮点：** 间隔重复调度 + 一键难度反馈
- **开发任务：** 在学习路径步骤和练习题后增加「掌握度按钮」：忘了 / 模糊 / 会了。新增资源完成后的三档反馈控件，并把反馈写入学习事件与路径步骤状态，用于生成下一次复习时间。

### Quizlet · 从模板创建

- **优先级：** P0 · **难度：** 低 · **体验提升：** 3/5
- **维度：** 社交 / 社区
- **亮点：** 共享学习集与复制再编辑
- **开发任务：** 在资源库增加「从模板创建」入口，内置机器学习高频概念、Python 基础语法两套复习卡模板（先做轻量示例学习集模板，不急着做完整社区）。

### 多邻国 · 连续学习 streak

- **优先级：** P0 · **难度：** 低 · **体验提升：** 5/5
- **维度：** 激励机制 / 交互体验
- **亮点：** 连续学习 streak + 即时动画反馈
- **开发任务：** 把学习成就馆的数据前置到首页和侧栏。在 AppSidebar 增加连续学习天数、小火苗式文本徽章和今日任务完成进度条。

### 多邻国 · 今日最小任务

- **优先级：** P0 · **难度：** 中 · **体验提升：** 5/5
- **维度：** 个性化 / 激励机制
- **亮点：** 每日目标 + 短任务闯关
- **开发任务：** 把学习路径拆成今日 10 分钟任务。在路径页顶部新增「今日最小任务」卡片，展示 1 个路径步骤、1 个复习资源、1 个小测验入口。

## 产品判断

LearnPath 已经具备「生成内容」和「规划路径」的骨架，下一步最值得补的是复习型产品的留存机制：**今日最小任务、掌握度反馈、连续学习天数、复习卡片**。建议先围绕 **P0** 做 1 周冲刺，形成「每天回来复习一次」的闭环。

## 一、资料库与上传体验

### 1. 快速入库（默认开启）

- 新增环境变量 `LIBRARY_FAST_INGEST=true`（默认）
- 上传文件后执行：**解析 → 分块 → 向量化**，跳过逐文件 LLM 分析与库级 AI 合成
- 上传耗时从「分钟级」降至「秒级～十几秒」
- 需要深度 AI 分析时，可在 `.env` 设置 `LIBRARY_FAST_INGEST=false`

### 2. 新建资料库与 AI 生成分离

- 选择「新建资料库」时：
  - 仅填写名称 + 选择文件
  - 按钮为 **「创建并入库」**，**不触发** AI 资源生成
  - 不再要求选择资源类型、填写生成主题
- 完成后自动跳转到资料库详情页

### 3. 资料库简介显示修复

- **问题**：简介区显示整段 JSON，而非可读文案
- **修复**：
  - 后端改进 JSON 解析，仅将 `description` 字段写入简介
  - 前端自动识别历史脏数据，只展示简介正文
- 涉及：`library_ingest_service.py`、`libraryDescription.ts`、`LibraryDetailPage.tsx`、`ResourceLibraryPanel.tsx`

### 4. 上传进度反馈

- 资料库详情页上传时显示进度条与百分比
- 提示文案改为「正在解析文件并入库…」

## 二、资源生成体验

### 1. 按类型设置生成数量（0–3）

- 每种资源类型右侧增加 **滚轮计数器**（`InputNumber`）
- 单次生成每类最多 **3** 个，设为 0 表示不生成
- 点击类型名称可快速在 0 ↔ 1 之间切换
- 预设：**标准套件**、**全选 ×1**、**全不选**
- 同类型多份时标题带「第 N 份」，Prompt 要求内容角度差异化

### 2. SSE 百分比进度条

- 生成弹窗内显示 **进度条 + 百分比 + 阶段文案**
- 修复「上传结束 → 生成开始」之间进度条消失的问题
- 阶段示例：准备上下文 → 各资源类型（如「讲解文档（2/3）」）→ 质检

### 3. API 扩展

`POST /api/resources/generate/stream` 请求体新增：

```json
{
  "resource_type_counts": { "doc": 2, "quiz": 1, "mindmap": 0 }
}
```

仍兼容旧字段 `resource_types`。

## 三、生成质量修复

### 1. 资源正文防「提示词复述」

- **问题**：部分主题生成时把 Prompt 字段当正文输出（如 `学习主题：`、`【资料库上下文】` 等）
- **修复**：
  - 检测 LLM 是否复述生成指令
  - 自动重试；失败则模板回退
  - 收紧 Prompt，禁止复述字段
- 涉及：`_resource_base.py`、`prompts.py`、`resource_context_service.py`、`mock_client.py`、`doc_agent.py`

### 2. 已有错误资源

- 修复仅影响**新生成**内容
- 旧资源需**重启后端后重新生成**才会更新

## 六、使用说明（队友 / 答辩）

1. 拉取代码后复制 `.env.example` → `.env`，自行配置 API Key
2. **只上传课件**：资源库 → 新建资料库 → 选文件 → 创建并入库
3. **AI 生成资源**：选「依据已有资料库」或「全网检索」→ 设置各类型数量 → 开始生成
4. 已有错误资源可在对应页面重新生成

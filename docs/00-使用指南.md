# 学径 · LearnPath 使用指南

> 面向大学生复习场景的 AI 学习系统使用说明  
> 更完整的工程文档见左侧目录；仓库根目录 [README.md](../README.md) 提供快速开始与 API 索引。

---

## 产品定位

**学径（LearnPath）** 把答疑、资料整理、资源生成、学习路径、AI 课堂与学习评估组织在同一工作台中。你只需要说明正在学什么、哪里不会，系统会围绕你的目标串联后续步骤。

### 适用对象

- 需要整理课程资料、备考或补齐知识漏洞的大学生
- 希望把课件、讲义、题库与代码统一管理的自学者
- 需要阶段化学习计划并持续跟踪进度的用户

### 核心目标

- 将分散资料整理为可检索、可复用、可生成内容的**资料库**
- 根据目标与资料生成可执行的**学习路径**
- 让对话、资源、课堂与评估围绕同一学习目标协同工作

---

## 推荐使用流程

### 1. 明确复习目标

在**智能对话**或**学习路径**中说明课程、考试范围、薄弱章节与可用复习时间。系统会据此更新学习画像与后续推荐。

### 2. 准备学习资料

- 选择已有**资料库**，或
- 上传课件、讲义、题目、代码等文件**新建资料库**

默认开启**快速入库**：上传后解析、分块、向量化，通常数秒至十几秒即可完成，无需等待 AI 全量分析。

### 3. 生成复习资源

在**资源库**中按类型选择需要的内容（讲解文档、练习题、代码案例、思维导图、课堂材料等）。支持每类 **0～3** 份批量生成，并可通过 SSE 查看实时进度。

### 4. 按路径推进

根据系统生成的阶段与子路径完成学习；可在路径节点进入 **AI 课堂**，并通过**学习评估**结果调整计划或触发路径重规划。

## 功能模块

| 模块 | 说明 |
|------|------|
| **智能对话** | 课程答疑、题目拆解、图片与文件追问，适合先解决具体卡点 |
| **资料库** | 管理上传资料、生成资源与索引，作为路径与课堂的材料来源 |
| **学习路径** | 阶段化复习计划，支持子步骤、完成标记与异步重规划 |
| **AI 课堂** | 围绕路径节点生成讲解、例题、练习与反馈 |
| **学习画像** | 记录薄弱点、偏好、进度与实时学情，影响推荐与讲法 |
| **学习评估** | 汇总练习、资源完成与路径进度，辅助判断是否需要重学 |

## 资料库规则

### 建立方式

| 方式 | 说明 |
|------|------|
| **依据现有资料库** | 选择已有库并填写诉求，系统读取说明、索引与资源后生成新库文档 |
| **依据上传资源** | 上传一个或多个文件；单文件生成说明，多文件额外生成关系说明 |
| **无资源新建** | 仅填写名称与诉求，系统通过检索与汇总形成基础说明文档 |

### 保存结构

每个资料库应包含：**说明文档**、**索引文档**与分类资源文件。多轮生成时的过程性中间文档不会作为主要学习资料长期展示。

### 读取逻辑

系统先读取说明与索引，再按资源类别与用户诉求读取具体资源，最后汇总生成最终文档。

## 学习路径

| 模式 | 适用场景 |
|------|----------|
| **自动规划** | 根据学习目标、资料库说明与已有资源决定阶段与子路径 |
| **按章节规划** | 课程资料结构清晰、考试按章节覆盖 |
| **按时间规划** | 临近期末、考研或竞赛前的冲刺安排 |
| **自定义规划** | 指定划分方式、重点章节、时间约束或必须使用的资源 |

路径为复习建议，不等同于课程教学大纲，实际安排仍应以教师要求与考试范围为准。

---

## 使用注意事项

1. **内容校对**：大模型生成内容需结合课程要求人工核对，尤其是公式、代码、题目答案与考试重点。
2. **资料质量**：扫描件、图片型 PDF 或格式异常文件可能影响解析，建议先 OCR 或重新导出。
3. **演示账号**：未登录时可使用演示学生体验；设置中支持清空或重置演示数据。
4. **API 密钥**：本地开发无密钥时可使用 `LLM_MOCK=true`，详见[开发指南](./02-开发指南.md)。
